N_149. Сайт: загрузка файлов во входящую очередь ГИПа

Что добавлено:
1. В карточке раздела появилась форма "Загрузить файл ГИПу на проверку".
2. Пользователь выбирает тип вставки: Файлы проекта, ТЗ, Исходники, Замечания.
3. Файл загружается через Edge Function в Яндекс.Диск:
   /Папка ГИПа/_Входящие_с_сайта/<год>/<месяц>/<id загрузки>/<имя файла>
4. После загрузки создается заявка в таблице Supabase opr_site_incoming_files.
5. В рабочие папки раздела файл не попадает до принятия ГИПом в локальной программе.

Что изменено:
- Edge Function yandex-disk-readonly расширена действием upload.
- Добавлены переменные .env.example:
  VITE_SITE_INCOMING_TABLE=opr_site_incoming_files
  VITE_YANDEX_INCOMING_FOLDER=_Входящие_с_сайта
  VITE_MAX_INCOMING_UPLOAD_BYTES=157286400

Проверка:
- Выполнена сборка сайта npm run build.
