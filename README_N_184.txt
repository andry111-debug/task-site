N_184_project_site_project_manager_role

Изменения относительно N_182:
1. Добавлена роль сайта "Руководитель проекта" / project_manager.
2. Роль добавлена в форму создания и редактирования учетных записей.
3. После входа пользователь с ролью project_manager сразу попадает в отдельный кабинет руководителя проекта.
4. На стартовом экране кабинета показаны 4 квадрата:
   - Общая информация;
   - Графики;
   - Совещания;
   - Финансирование.
5. Раздел "Общая информация" показывает здания, описания, площади и изображения из существующих карточек зданий.
6. Раздел "Графики" содержит выбор: Проектирование, ППТ, РНС.
7. Раздел "Совещания" содержит блок последних протоколов, актуальную повестку и задачи по ответственным.
8. Раздел "Финансирование" содержит график потребности в финансах на ближайшие 3 месяца.
9. Прямой доступ к Supabase не возвращался: сохранена схема работы через Vercel /api и GIP API.

Примечание:
- Совещания, РНС и финансирование пока оформлены как интерфейсные блоки с рабочими стартовыми данными. При следующем шаге их можно подключить к отдельным таблицам Supabase или к выгрузке из локальной программы ГИПа.

Проверка:
- npm ci — успешно.
- npm run build — успешно.
