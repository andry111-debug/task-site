N_219. Сайт: заявки на удаление файлов ГИПу.

Порядок применения:
1. В автодеплое сайта включить выполнение SQL.
2. Выполнить SQL из supabase_sql/, включая N_219_delete_file_requests.sql.
3. Задеплоить сайт.

GIP API менять не требуется: используется существующий доступ к таблице opr_site_incoming_files.

Новая логика:
- В карточке раздела ГАПА рядом со скачиванием файла отображается красная кнопка "Удалить".
- По нажатию создается заявка в opr_site_incoming_files с request_type='delete_file'.
- Файл физически не удаляется сайтом.
