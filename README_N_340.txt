N_340_project_site_plus_gip_api_archive_local_download_fix

Назначение:
- исправляет зависание общего архива нормоконтроля на 88%;
- готовый ZIP больше не загружается обратно на Яндекс.Диск;
- GIP API сохраняет ZIP во временную папку сервера и отдаёт прямой ссылкой;
- прогресс-бар остаётся на сайте.

Установка:
1. Выбрать этот ZIP в автодеплое.
2. Включить галочку обновления GIP API через deploy-agent.
3. SQL не включать.
4. После установки проверить /api/health: версия GIP API должна быть N_340.

Примечание:
Если готовая ссылка не открывается из браузера, в .env GIP API можно задать GIP_API_PUBLIC_URL с публичным адресом API. Обычно это не требуется, адрес берётся из запроса автоматически.
