N_330_project_site_norm_controller_yandex_diagnostics

База: N_328_project_site_norm_controller_published_path_priority

Изменения:
- В кабинете нормоконтролера у каждого файла добавлена кнопка «Диагностика».
- Кнопка проверяет путь через GIP API /yandex:
  1) показывает путь, который сайт использует для открытия файла;
  2) показывает поля из norm_control_files;
  3) показывает найденную карточку файла из opr_site_section_files, если она найдена;
  4) выполняет list родительской папки;
  5) выполняет проверку download-ссылки без вывода самой временной ссылки;
  6) проверяет варианты /Внутренняя технологии/... и /Внутренняя Технологии/...
- Лог можно скопировать кнопкой «Скопировать лог» и передать для анализа.
