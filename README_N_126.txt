N_126_project_site_yandex_disk_readonly

Назначение версии
-----------------
Эта версия реализует только чтение Яндекс.Диска из карточки раздела на сайте.
Запись, загрузка, создание папок, перемещение, переименование и удаление файлов специально не реализованы.

Что изменено
------------
1. В карточке раздела добавлен блок "Яндекс.Диск / только чтение".
2. Сайт рассчитывает каталоги для проверки по данным, которые выгружает локальная программа:
   - Файлы проекта -> common_storage_folder
   - ТЗ -> common_storage_folder/ТЗ
   - Исходники -> /Программные файлы/OPR-site/upload_queue/Исходники/<здание>/<стадия>/<раздел>
   - Замечания -> /Программные файлы/OPR-site/upload_queue/Замечания/<здание>/<стадия>/<раздел>
3. Для каждого каталога есть кнопка "Проверить каталог".
4. Если каталог найден, сайт показывает список файлов/папок.
5. Для файлов доступна кнопка "Скачать", которая получает временную ссылку через серверную функцию.

Важно
-----
Сайт не хранит токен Яндекс.Диска во фронтенде.
Токен должен храниться только в секретах Supabase Edge Function.

Переменные фронтенда
--------------------
В .env.local сайта можно добавить:

VITE_YANDEX_DISK_FUNCTION=yandex-disk-readonly
VITE_YANDEX_SERVICE_ROOT=/Программные файлы/OPR-site

Если их не указать, будут использованы эти значения по умолчанию.

Секреты Edge Function
---------------------
В Supabase для функции нужен секрет:

YANDEX_ACCESS_TOKEN=<токен Яндекс.Диска>

Не добавлять токен в React, GitHub, .env.local сайта или Supabase public table.

Развертывание Edge Function через Supabase CLI
----------------------------------------------
Один раз нужно войти в Supabase CLI и привязать проект.
Далее пример команд:

supabase secrets set YANDEX_ACCESS_TOKEN="ВАШ_ТОКЕН" --project-ref ВАШ_PROJECT_REF
supabase functions deploy yandex-disk-readonly --project-ref ВАШ_PROJECT_REF

После развертывания функции можно обновлять сайт через автодеплой.

Проверка
--------
1. Обновить сайт через автодеплой архивом N_126.
2. Развернуть функцию yandex-disk-readonly.
3. Зайти под архитектором.
4. Открыть специализированный интерфейс.
5. Выбрать здание и раздел.
6. В карточке раздела нажать "Проверить каталог" для "Файлы проекта" и "ТЗ".

Ожидаемый результат
-------------------
Сайт должен показать путь Яндекс.Диска, который он рассчитал из common_storage_folder,
и список файлов в этом каталоге. Это позволит проверить сопоставление каталогов до включения записи.
