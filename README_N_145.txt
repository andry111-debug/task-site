N_145_project_site_archive_download_fix

Изменения:
1. В карточках зарегистрированных документов больше не отображаются комментарии/служебные подписи вроде "Исходник из локальной программы".
2. Убран информационный блок под заголовком "Зарегистрированные документы".
3. Исправлено скачивание архивом для разделов "Исходники" и "Замечания".

Причина исправления архива:
браузер не всегда может скачать временные ссылки Яндекс.Диска через fetch из-за CORS. Теперь сайт получает содержимое файлов через Edge Function yandex-disk-readonly с action=content и уже из этих данных формирует ZIP.

Обязательно:
после обновления сайта нужно обновить код Edge Function yandex-disk-readonly в Supabase Dashboard, потому что добавлено действие action=content.
