N_277. Исправление загрузки результатов нормоконтроля

База: N_276_project_site_blank_login.

Что изменено:
- При загрузке результатов нормоконтроля сайт больше не отправляет поле mime_type в таблицу opr_site_section_files.
- Это исправляет ошибку Supabase schema cache: Could not find the 'mime_type' column of 'opr_site_section_files'.
- Сама загрузка файла остается chunked через GIP API N_169.
- Путь загрузки результатов нормоконтроля не изменялся: /Для Технического заказчика/Стадия П/<проект>/<раздел>/нормаконтроль/<файл>.
- SQL-миграции не требуются.

Установка:
1. В автодеплое выбрать архив N_277_project_site_norm_result_schema_fix.zip.
2. SQL не включать.
3. Выполнить обычный автодеплой сайта.
4. Проверить загрузку результата нормоконтроля.
