N_160_project_site_via_gip_api

Изменение архитектуры сайта:
- сайт больше не обращается к Supabase напрямую из браузера;
- все запросы к базе идут через GIP API;
- все операции с Яндекс.Диском идут через GIP API;
- пользователю без VPN нужен доступ только к сайту и GIP API.

Основной параметр сайта:
VITE_GIP_API_BASE_URL=/api

Если API размещен отдельно:
VITE_GIP_API_BASE_URL=http://IP_ИЛИ_ДОМЕН:3100/api

SQL и локальная программа в этой версии не менялись.
