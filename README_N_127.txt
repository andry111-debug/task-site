N_127_project_site_yandex_disk_existing_gip_folders_readonly

Изменения относительно N_126:

1. Чтение Яндекс.Диска остается только read-only.
2. Файлы проекта читаются из common_storage_folder.
3. ТЗ читается из common_storage_folder/ТЗ.
4. Исходники теперь читаются из существующей структуры локальной программы:
   gip_storage_folder/исходники/GP_<номер>_<здание>__<стадия>_<раздел>
5. Замечания теперь читаются из существующей структуры локальной программы:
   gip_storage_folder/замечания/GP_<номер>_<здание>__<стадия>_<раздел>
6. Служебная очередь /Программные файлы/OPR-site/upload_queue пока не используется для чтения исходников и замечаний.
7. Запись на Яндекс.Диск, создание папок, загрузка, удаление, перемещение и переименование файлов не реализованы.

SQL выполнять не требуется.
Edge Function yandex-disk-readonly менять не требуется, если она уже создана и работает.
