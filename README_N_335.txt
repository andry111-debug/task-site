N_335_project_site_plus_gip_api_archive_diagnostics

Назначение:
- Объединённый архив для автодеплоя сайта и GIP API.
- Сайт: добавлена кнопка «Диагностика архива» в кабинете нормоконтролера.
- GIP API: сохранена версия N_333 с нечувствительным к регистру поиском путей Яндекс.Диска.

Как проверить:
1. Установить архив через автодеплой.
2. Включить обновление GIP API через deploy-agent, если нужно переустановить API.
3. SQL не требуется.
4. В кабинете нормоконтролера выбрать раздел.
5. Нажать «Диагностика архива».
6. Нажать «Скопировать лог» и передать лог в чат.

Диагностика проверяет:
- сколько файлов попало в общий архив;
- какой путь вычислен для каждого файла;
- получает ли GIP API временную ссылку download;
- скачивается ли содержимое через action=content;
- добавляется ли файл в ZIP;
- собирается ли ZIP в памяти браузера.

Временные ссылки скачивания и содержимое файлов в лог не выводятся.
