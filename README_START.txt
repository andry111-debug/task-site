N_118_pycharm_auto_deploy_supabase_fixed

Назначение:
Обновленная утилита автодеплоя сайта + Supabase SQL.

Главное исправление версии N_118:
- npm и git больше не запускаются короткими командами npm.cmd / git.exe;
- программа сама ищет полные пути:
  C:\Program Files\nodejs\npm.cmd
  C:\Program Files\Git\cmd\git.exe
- внутри процесса дополнительно расширяется PATH;
- рабочая папка по умолчанию:
  C:\Projects\ОПР\_Сайт
- git add больше не использует git add -A, чтобы случайно не отправить _deploy_backups и _chatgpt_logs;
- лог автоматически пишется в:
  C:\Projects\ОПР\_Сайт\_chatgpt_logs
- добавлена кнопка "Создать лог для ChatGPT".

Как запускать:
1. Распаковать архив.
2. Запустить run_auto_deploy.bat.
3. В поле "Папка проекта" должно быть:
   C:\Projects\ОПР\_Сайт
4. Выбрать zip-архив обновления сайта.
5. Нажать "Проверить архив".
6. Нажать "Выполнить автодеплой".
7. Если будет ошибка, нажать "Создать лог для ChatGPT" и отправить txt-файл.

SQL:
- Для выполнения SQL через эту программу нужен пакет psycopg2-binary.
- Если он не установлен, можно пока снять галочку SQL и выполнить SQL вручную в Supabase SQL Editor.

Важно:
- Не использовать вручную git add .
- Не отправлять в GitHub папки _deploy_backups и _chatgpt_logs.
